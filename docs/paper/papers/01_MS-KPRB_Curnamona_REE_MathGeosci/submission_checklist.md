# Submission checklist — Mathematical Geosciences (Springer Nature)

Built from `papers/_build/content/ms_kprb.js` (+ `_ms_kprb_results.js`); rebuild instead of editing numbers.

Requirements applied (Springer Nature journal; guide: https://link.springer.com/journal/11004/submission-guidelines — the page redirects automated clients to a
sign-in, so confirm the items below in a browser before submitting):
- Title page with title, authors, affiliations, corresponding e-mail, ORCID (placeholders in square brackets).
- Abstract 150–250 words without references; 4–6 keywords.
- Author–year citations; alphabetical reference list with DOIs as links.
- Equations as editable Word equations; variables italic, vectors bold.
- Figures embedded after first citation with captions "Fig. n"; figure files 600 dpi in `figures/` (Fig_1 …); no titles inside figures.
- Tables with captions above; continuous line numbering; SI units.
- "Declarations" before the references (Funding, Competing interests, Data availability, Code availability, Author contributions).
- Use of a large language model documented in the Methods (Springer Nature policy), not as an author.
- Publishing model: hybrid — no charge on the standard (subscription) route; open access (Open Choice) is optional.
